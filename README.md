# 🌸 LUMIÈRE COSMETICS - Luxury Shopify Store & Theme

> A complete, luxury Shopify store and OS 2.0 Theme inspired by high-end botanical skincare aesthetics. Includes an interactive web app with built-in Admin CMS & customizer, plus an official Shopify theme package ready to publish live.

## ✨ Features

- **Luxury Brand Aesthetics**: Soft blush pink (`#C87D70`), rose gold, and cream palette with Google Fonts (*Cormorant Garamond* / *Inter*).
- **Sticky Header & Announcement Bar**: Promo code banner (`GLOW20`), live instant product search, customer account access, and real-time cart badge counter.
- **Hero Section**: High-conversion hero layout with trust highlight badges (*Natural Ingredients, Cruelty Free, Paraben Free*).
- **Trust Highlights Bar**: 4 key value propositions (*Natural Ingredients, Dermatologically Tested, Premium Quality, Eco-Friendly*).
- **Category Grid**: 6 curated categories (*Skin Care, Makeup, Hair Care, Fragrance, Face Masks, Gift Sets*).
- **Brand Story Section**: Narrative with model imagery and benefit pillars (*Natural & Safe, Visible Results, For All Skin Types*).
- **Best Sellers ("Our Most Loved Products")**: Interactive product cards with Quick View, ratings, and instant Add to Cart.
- **Our Promise Banner**: Signature rose ribbon highlighting clean beauty commitments.
- **Interactive Multi-Page Flows**:
  - **Collection / Catalog Page**: Filter by category and sort by price/bestsellers.
  - **Product Detail Page (PDP)**: Multi-image gallery, volume variant selector (30ml, 50ml, 100ml), quantity stepper, express Shop Pay button, and collapsible accordion tabs (*Ingredients, How to Use, Clinical Results, Shipping*).
  - **Slide-out Cart Drawer**: Dynamic free shipping progress bar, promo code engine (`GLOW20`), and price breakdown.
  - **Simulated Shopify One-Page Checkout**: Express checkout (Shop Pay, PayPal, GPay), customer address form, credit card fields, and order confirmation.
- **⚡ Built-in Store Admin & CMS**:
  - **Live Theme Customizer**: Real-time editing of headlines, subtitles, promo codes, and brand colors.
  - **Product Catalog Manager**: Add, edit, or delete products with automatic LocalStorage sync.
  - **Orders & Analytics Dashboard**: Revenue tracking, order history, and average order value.
- **Official Shopify OS 2.0 Theme (`shopify-theme/` & `lumiere-shopify-theme.zip`)**:
  - Valid Liquid templates (`index.json`, `product.json`, `collection.json`, `cart.json`).
  - Customizable sections and theme settings schema (`settings_schema.json`).
- **Product Catalog CSV (`shopify-products-import.csv`)**:
  - Standard Shopify CSV format for one-click import into Shopify Admin.

## 🚀 How to Publish Live on Shopify

1. **Upload Theme**:
   - Go to **Shopify Admin** (`https://admin.shopify.com/store/your-store`).
   - Navigate to **Online Store → Themes**.
   - Click **Add theme → Upload zip file** and choose `lumiere-shopify-theme.zip`.
   - Click **Publish**.
2. **Import Products**:
   - In Shopify Admin, click **Products → Import**.
   - Select `shopify-products-import.csv` and click **Upload and continue**.
3. **Customize in Theme Editor**:
   - Go to **Online Store → Themes → Customize** to edit text, images, and colors visually.
