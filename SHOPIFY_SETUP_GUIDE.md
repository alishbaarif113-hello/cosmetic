# 🌸 Lumière Cosmetics - Official Shopify Live Publishing Guide

Congratulations on your new luxury Shopify store! This package includes both the **interactive local web application with built-in Admin CMS** and the **official Shopify OS 2.0 theme ZIP** ready to publish live.

---

## 📁 Package Contents

| File / Folder | Description |
| :--- | :--- |
| `index.html` | Interactive, full-store preview with live Admin CMS, Customizer & Checkout |
| `styles.css` | Luxury design system matching the reference aesthetic |
| `app.js` | State controller, cart drawer, catalog filtering, and local storage |
| `assets/images/` | High-resolution photography of Lumière cosmetics products & models |
| `shopify-theme/` | Full Shopify OS 2.0 Theme directory (Liquid, Sections, Snippets, JSON) |
| `lumiere-shopify-theme.zip` | Ready-to-upload archive for Shopify Theme Store / Admin |
| `shopify-products-import.csv` | Standard Shopify product CSV containing all variants, tags, and prices |

---

## 🚀 Step 1: Upload the Theme to Shopify Live

1. Log in to your **Shopify Admin** dashboard (e.g. `https://admin.shopify.com/store/your-store-name`).
2. In the left navigation sidebar, click **Online Store** → **Themes**.
3. In the **Theme library** section, click **Add theme** → **Upload zip file**.
4. Select `lumiere-shopify-theme.zip` from your computer.
5. Once uploaded, click **Actions** → **Publish** to make it your live active store theme!

---

## 📦 Step 2: Import Your Product Catalog

1. In the Shopify Admin sidebar, click **Products**.
2. In the top right corner, click **Import**.
3. Select `shopify-products-import.csv`.
4. Click **Upload and continue**, then **Import products**.
5. All products (Radiance Serum, Hydrating Day Cream, Gentle Cleanser, Toner, Perfume, etc.) with prices, inventory levels, and variants will be loaded instantly.

---

## 🎨 Step 3: Customize via Shopify Theme Editor

1. Go to **Online Store** → **Themes** → **Customize**.
2. You can visually edit:
   - Announcement Bar text and discount codes.
   - Hero headlines, banner photography, and call-to-actions.
   - Featured bestseller collections and category cards.
   - Brand story imagery and benefit highlights.
   - Brand color tokens (Blush Pink, Champagne, Charcoal).

---

## 💻 Local Testing & Visual Admin CMS

You can also test and manage everything locally by opening `index.html` in any web browser:
- Click **"⚡ Admin & CMS"** in the top navigation or the bottom floating button to:
  - Edit hero titles, announcement texts, and brand colors in real-time.
  - Add, edit, or delete products with automatic local storage persistence.
  - Test cart, discount code `GLOW20`, and complete simulated orders.
  - View simulated revenue and analytics.
